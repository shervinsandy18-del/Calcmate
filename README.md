# CalcMate 🧮

A clean, responsive calculator web application built with HTML, CSS and JavaScript.

## Features

- Basic arithmetic operations
- Percentage and positive/negative toggle
- Decimal calculations
- Delete and clear controls
- Keyboard support
- Calculation history using Local Storage
- Dark/light theme
- Responsive design for desktop and mobile
- Error handling

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage

## Run Locally

Open `index.html` in a browser.

## GitHub Pages

Push the project to a GitHub repository and enable GitHub Pages from:

**Repository → Settings → Pages → Deploy from branch → main → /(root)**
